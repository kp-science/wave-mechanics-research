5. MC2

14. ค → จ → ฉ → ข → ก → ง
ยุคพลังค์ (ค) → ยุครังสี เกิดควาร์ก/อิเล็กตรอน (จ) → ยุคนิวคลีออน ควาร์กรวมเป็นโปรตอน/นิวตรอน (ฉ) → BBN เกิดนิวเคลียส H/He (ข) → รีคอมบิเนชัน กำเนิด CMB (ก) → ปัจจุบัน (ง)
หลักจำ: ของเล็กเกิดก่อน — อนุภาคพื้นฐาน → โปรตอน/นิวตรอน → นิวเคลียส → อะตอม → ดาวและกาแล็กซี
15. ตอบ ข้อ 2

(2) สเปกตรัมเป็นการแผ่รังสีวัตถุดำอุณหภูมิ 2.725 K ตรงกับคำทำนายของทฤษฎีบิกแบงที่ว่า เอกภพเคยร้อน-หนาแน่น แล้วเย็นลงเมื่อขยายตัว — แบบจำลองคู่แข่ง (เช่น เอกภพคงที่ไม่มีจุดเริ่ม) อธิบายการมีอยู่ของรังสีพื้นหลังนี้ไม่ได้
